# Fonts embedded in exported .docx files

Generated by `backend/scripts/build-word-fonts.py` from the `@fontsource/*` packages (latin subset).
All 17 families are licensed under the **SIL Open Font License 1.1**, which permits embedding and
redistribution (embedding flag `fsType = 0`). Each family's license text ships inside its
`@fontsource/<name>` package (`LICENSE` file).

Add a font: install its `@fontsource` package in `frontend`, add it to `FAMILIES` in the script, run it,
and commit the new `.ttf` files. Fonts without files here fall back to a Word-safe font automatically.
